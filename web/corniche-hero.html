What this is

Two renders. No video, no AI, no library.

Everything above is driven by two images you already own — the day and dusk exteriors from page 3 and page 2 of the Corniche brochure. They were rendered from an identical camera position, which is the whole trick: because the geometry lines up pixel for pixel, the tower can be cross-dissolved through a full day-to-night arc without a single generated frame.

The night stage is graded in the canvas at runtime — the dusk plate darkened through a multiply pass, then re-composited in lighten mode so only the lit windows survive. That is why the facade goes dark while the apartments come up warm.

Where the real sequence lands

The rig doesn't change when the frames arrive.

The renderer already takes an array of plates and a scroll position. Swapping two stills for two hundred frames is a change of input, not of architecture — the pin, the scrub, the device-pixel-ratio handling and the reduced-motion fallback all stay exactly as they are.

// today — two plates, cross-dissolved
const plates = [ day, dusk ];
draw(progress);

// once Higgsfield / Kling frames are exported
const plates = await preload(
  240, i => `frames/frame-${String(i).padStart(4,'0')}.webp`
);
draw(progress); // same call — picks the nearest frame instead of blending two

Known limits

  • Source resolution is 960px. Extracted from the 2017 brochure PDF, so it softens on a large display. The full-size originals exist in RWD's media library — the files ending -Hi-res. One email fixes this, and nothing else needs to change.
  • The base of the frame is cropped. Cars, people and trees were swapped between the two render passes, so the bottom tenth ghosts during the dissolve. Trimming it removes the artefact and keeps the pergola crown intact.
  • Dusk is not night. The second plate still holds colour in the sky, so the night stage is a grade rather than a true night render. A genuine night plate at this same camera would replace it directly.
  • This arc is one of three beats. Construction and the rooftop orbit still need generated frames — but they chain onto this rig through the same start-frame/end-frame anchors.
